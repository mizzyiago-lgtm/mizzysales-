How buying works
  1. Install and open the app you want to verify before buying.
  2. Pick the country.
  3. Pick the service — each one shows its price.
  4. Tap Buy Number — your wallet is charged and the number is reserved for you.
  5. Your code appears automatically on your Active Number page and in your orders below — no refresh needed.
  6. No code in time? You are refunded automatically, or tap Cancel & Refund when it is offered.
Notifications you will get
  • Live countdown showing how long is left on your number
  • Instant on-page alert the moment your OTP code arrives
  • Automatic refund notice if no code arrives before time runs out
  • Wallet balance updates immediately after every charge or refund

How It Works & Refund Rules

  • Your wallet is charged the moment you buy — this reserves a real, working number for you
  • You have about 20 minutes to receive your SMS/OTP code on that number
  • If a code arrives in time, the sale is final — you keep the code
  • If no code arrives before time runs out, you're refunded automatically — no action needed
  • Want your money back sooner? Tap "Cancel & Refund" on your order when it is offered, before a code arrives
  • Once a code has been delivered, that number can no longer be cancelled or refunded
